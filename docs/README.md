# CoGe-GCD Project Homepage

Static project page for **CoGe-GCD: Reframing Generalized Category Discovery with Compositional Generalization** (ICML 2026).

## Preview locally

From this directory, run any static HTTP server:

\`\`\`bash
python3 -m http.server 8000
\`\`\`

Open [http://localhost:8000](http://localhost:8000). The language switch in the top-right opens the Chinese version at \`zh/\`.

The page is self-contained: figures are in \`assets/\`, the paper is \`CoGe-GCD-paper.pdf\`, and no build step is required.
