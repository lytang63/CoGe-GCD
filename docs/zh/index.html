CoGe-GCD

Reframing Generalized Category Discovery with Compositional Generalization

Luyao Tang、Jiewei Zheng、Kunze Huang、Chaoqi Chen、Yue Huang、Cheng Chen

The University of Hong Kong · Xiamen University · Shenzhen University

📄论文 ⌘代码 ↗项目主页 { }BibTeX

广义类别发现需要在带标签与无标签图像混合的开放世界中，同时识别 known 与 novel 类别。CoGe-GCD 进一步追问：模型能否复用已经学到的视觉原语，并通过它们的新组合发现新类别？

🧩Compositional Perception将 patch evidence 组织为紧凑、可复用的 primitive 词汇。
◎Generalizing Induction校准诱导出的几何结构，使 known-to-novel 外推保持有序。
🔌Drop-in Interface置于视觉 backbone 与任意现有 GCD head 之间即可使用。

一句话概括

CoGe-GCD 将 GCD 重新表述为组合泛化问题：先把 patch tokens 变成相互竞争、由图像上下文决定的 primitives，再保留它们的空间与关系几何，最后交给原有 GCD head 做 known/novel 判断。Backbone、训练目标、聚类协议与 head 均无需改变。

💡 核心洞见

Novel 类别是新的组合，而不是任意的点云。

开放世界中的类别可能是陌生的，但组成它的部件、属性和关系并不陌生。因此，发现过程需要一条从感知组织到归纳外推的显式链路。

为什么 GCD 需要结构

整体 embedding 往往隐藏了“为什么 novel 类别合理”的中间证据。CoGe-GCD 在聚类前把这部分证据显式化。

模型学习什么

一组由图像上下文决定的 primitive 竞争 token 支持，并通过 soft memberships 形成高阶 token–primitive 几何。

哪些部分保持不变

CoGe-GCD 是 backbone 与 projection head 之间的 inductive-bias 模块；原有 loss、optimizer、head 与 clustering 均可复用。

🧮 核心公式

从潜在 primitive 到几何校准证据

下面的公式对应论文中的两阶段设计：先构造组合表示，再保留归纳所需的几何结构。

01

潜在组合流形

X = A∗P∗ + E

观测到的 patch features 由有限 primitive basis 与各向同性噪声生成，且 M ≪ min(N, D)。

02

Primitive competition

ΔP = φ([avg(X), max(X)])
P = P0 + ΔP
Ai,m = exp(Si,m/τ) / Σk exp(Sk,m/τ)

每个 primitive 在 token 上分配单位概率质量，鼓励不同 primitive 专门化而非塌缩。

03

Evidence consolidation

F = Df−1A⊤X
X′ = σ(Dt−1A σ(Df−1A⊤XWe⊤)Wn⊤)

信息沿 token → primitive → token 流动，在进入 GCD head 前放大连贯群组并抑制噪声关联。

04

几何保持校准

Gtok = AA⊤,   Gfac = A⊤A
Πi,j ∝ exp(−‖pi − pj‖² / 2)
Ã = ½(A + G(A))

在保持 column-stochastic 语义的同时注入 proximity 与 continuity，为 Generalizing Induction 提供结构化基底。

🔎 模型发现了什么

Primitive 成为可复用的视觉证据。

跨样本观察时，同一个 primitive index 往往关注语义上对应的区域。模型不再只能用一个整体 token 去解释每一张图像。

📊 实验证据

跨方案、跨尺度的稳定收益。

CoGe-GCD 在 CUB-200、Stanford Cars、FGVC-Aircraft、CIFAR-10、CIFAR-100 和 ImageNet-100 上评估，同时保持原始 GCD protocol。

开放世界视角

“先组织证据，再推断新颖性”这一分离并不局限于单一 benchmark。它可以迁移到 continual discovery、domain-shifted discovery、open-world recognition 以及更多类别集合持续变化的任务中。我们期待研究者使用新的 backbone 与任务尝试这一接口，并分享反馈、失败案例和扩展方向。
